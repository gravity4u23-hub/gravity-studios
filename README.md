# Gravity Studios

Sales site for Gravity Studios: remote AI services for local businesses (GBP audit, Growth Diagnostic, Blog Engine, Missed-Call Rescue). The whole site is one file, `index.html`.

- **Update the page:** edit `index.html`, open a PR, Atlas reviews, then merge (see `HIVEMIND.md`).
- **Deployment:** not decided yet — see Atlas open item #2 in `ATLAS_REVIEW.md`.
- **`research/`:** transcripts and notes Grok files for the agents; `research/INBOX.md` lists new items to integrate.
- **Agents:** `HIVEMIND.md` (roles and rules), `ATLAS_REVIEW.md` (reviews), `CURRENT_TASK.md` (progress), `CLAUDE.md` (Claude's build standards).
